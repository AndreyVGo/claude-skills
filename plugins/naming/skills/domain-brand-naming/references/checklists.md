# Чек-листы ручной проверки

Выдаются пользователю, когда режим работы — СЕТЬ или ОФЛАЙН, либо когда база
не открылась в браузере. Нумерация сквозная, в выдаче ссылайся номером.
Каждый чек-лист самодостаточен: пользователь выполняет его, не задавая вопросов.

---

## Чек-лист 1. Товарные знаки, РФ

1. Бесплатно и неполно: `fips.ru/registers-web/` — только выдача документа
   по известному номеру. Поиска по обозначению здесь **нет**.
2. Полный поиск на тождество и сходство:
   - платная ИПС ФИПС (`new.fips.ru`, регистрация и тариф), либо
   - заявление на предварительный информационный поиск в ФИПС (платная услуга,
     результат официальный), либо
   - патентный поверенный.
3. Что искать: точное обозначение, фонетические варианты, транслитерацию
   латиница↔кириллица, перевод, однокоренные и усечённые формы.
4. Классы: заявленные плюс любые, где есть однородные товары и услуги.
5. Отдельно: перечень общеизвестных знаков ФИПС.
6. Конфликт = тождество или сходство до степени смешения по однородным товарам.
7. Помни про слепой период: заявки последних 2–6 месяцев не опубликованы
   и не видны никому.

## Чек-лист 2. Товарные знаки, международные базы

1. WIPO Global Brand Database: `branddb.wipo.int` — поиск по обозначению,
   фильтр по Ниццким классам и по указанным странам. Капча при автоматическом доступе,
   вручную открывается нормально.
2. TMview: `tmdn.org/tmview` — 70+ ведомств одним запросом.
3. EUIPO eSearch: `euipo.europa.eu` — знаки ЕС.
4. USPTO: `tmsearch.uspto.gov` — знаки США, включая заявки intent-to-use.
5. Для США дополнительно поищи неформальное коммерческое использование имени:
   поисковик, каталоги компаний, магазины приложений. Common law права
   регистрации не требуют.
6. Для Китая: `sbj.cnipa.gov.cn` — латиница и вероятные транслитерации иероглифами.

## Чек-лист 3. Реестры юридических лиц

1. РФ: `egrul.nalog.ru` — поиск по наименованию. Капча.
2. ЕС: национальные реестры через `e-justice.europa.eu` (Business Registers).
3. США: реестры штатов (Secretary of State) плюс `search.sunbiz.org` для Флориды,
   `bizfileonline.sos.ca.gov` для Калифорнии.
4. Конфликт = действующее юрлицо с тем же или сходным наименованием в вашей отрасли.
   Старшее фирменное наименование блокирует регистрацию знака.

## Чек-лист 4. Поисковая выдача

Для каждого целевого рынка, в режиме инкогнито и с региональной привязкой:

1. Google: запрос `<имя>`. Смотри: не появилось ли «Showing results for…» или
   «Возможно, вы имели в виду…»; кто в топ-10; сколько всего результатов.
2. Google: запрос `<имя> <категория продукта>` — есть ли в топ-10 чужой бизнес.
3. Яндекс: то же самое для РФ и СНГ.
4. Автоподсказка: начни набирать имя и посмотри, что предлагается.
5. Конфликт = подмена запроса, либо крупный бренд в топ-3, либо выдача целиком
   занята словарным значением в вашей же категории.

## Чек-лист 5. Соцсети и магазины приложений

Машинно не проверяются, только глазами, обязательно в разлогиненном браузере:

1. Instagram: `instagram.com/<имя>` — залогиненным виден login wall и ложный 200.
2. X: `x.com/<имя>`.
3. Telegram: `t.me/<имя>` — отдаёт 200 на любой хэндл, смотри содержимое страницы.
4. Google Play: `play.google.com/store/search?q=<имя>` — 200 всегда, смотри выдачу.
5. Площадки, релевантные рынку: WeChat и Weibo для Китая, LINE для Японии,
   KakaoTalk для Кореи.

## Чек-лист 6. Цена и статус домена

1. Премиальность: проверь имя у любого крупного регистратора — RDAP покажет
   «свободен», а цена может быть в тысячах долларов.
2. Вторичный рынок: `sedo.com`, `dan.com`, `afternic.com` — если домен занят,
   есть ли он в продаже и по какой цене.
3. Освобождение: если статус `redemptionPeriod` или `pendingDelete` — домен
   вернётся в свободные через 30–75 дней. Сервисы бэкордера: `dropcatch.com`,
   `backorder.ru` для `.ru`.
4. Требования зоны к регистранту — см. `references/legal.md`.

## Чек-лист 7. Лингвистика

Для каждого языка из списка EN, ES, PT, FR, DE, RU, ZH, JA, AR, TR, HI:

1. Значение слова, если оно существует.
2. Созвучия: произнеси вслух, поищи в сленговых словарях
   (`urbandictionary.com` для EN, аналоги для других языков).
3. Как имя прочтёт носитель, не знающий вашего языка.
4. Проверка живым носителем — единственный надёжный способ. Для рынков,
   куда вкладываются деньги, делается всегда.
