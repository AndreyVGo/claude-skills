# claude-skills

Скиллы для [Claude Code](https://claude.com/claude-code) и совместимых CLI-агентов.

Каждый скилл — самодостаточный каталог с `SKILL.md`: инструкции, справочные
материалы и скрипты. Агент подхватывает скилл по описанию во фронтматтере
и следует ему вместо поведения по умолчанию.

## Скиллы

| Скилл | Что делает |
|---|---|
| [domain-brand-naming](skills/domain-brand-naming) | Подбор доменных имён и словесных товарных знаков под запуск на нескольких рынках: генерация имён, проверка доменов, охраноспособность знака, конфликты с чужими правами, поисковая уникальность, бюджет защиты |

## Установка

Клонировать и связать нужный скилл симлинком:

```bash
git clone https://github.com/AndreyVGo/claude-skills.git
ln -s "$PWD/claude-skills/skills/domain-brand-naming" ~/.claude/skills/domain-brand-naming
```

Либо скопировать каталог скилла в `~/.claude/skills/` — симлинк удобнее тем,
что `git pull` обновляет скилл на месте.

Проверить, что скилл виден, можно командой `/skills` в Claude Code.

## Принципы

Скиллы здесь написаны под одно требование: **результат должен выдерживать
проверку пользователем**. Отсюда следуют правила, общие для всех:

- разделять то, что агент может проверить сам, и то, что закрыто капчей,
  логином или JS-рендером — по второму выдаётся чек-лист, а не выдуманный результат;
- ссылаться на стабильные URL, а не на поисковые запросы в SPA;
- честное «не проверено» всегда дешевле правдоподобной выдумки;
- каждый скрипт проверяется на живых данных до того, как попадёт в репозиторий.
