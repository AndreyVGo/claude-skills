# claude-skills

Скиллы для [Claude Code](https://claude.com/claude-code), собранные как маркетплейс плагинов.

Каждый скилл — самодостаточный каталог с `SKILL.md`: инструкции, справочные
материалы и скрипты. Агент подхватывает скилл по описанию во фронтматтере
и следует ему вместо поведения по умолчанию.

## Установка

В Claude Code:

```
/plugin marketplace add AndreyVGo/claude-skills
/plugin install naming@claude-skills
```

Либо из терминала:

```bash
claude plugin marketplace add AndreyVGo/claude-skills
claude plugin install naming@claude-skills
```

Обновление — `/plugin update naming`, удаление — `/plugin uninstall naming`.

## Плагины

### naming

Подбор доменных имён и словесных товарных знаков под запуск на нескольких рынках.

Содержит скилл `domain-brand-naming`: бриф, генерация фантазийных и произвольных
имён уровня Яндекс/Amazon/Ozon, воронка проверок с учётом реального бюджета
сетевых вызовов, справочник по праву товарных знаков и ограничениям доменных зон,
готовые чек-листы ручной проверки и скрипт машинной проверки имени.

Срабатывает на «придумай название», «подбери домен», «проверь товарный знак»,
«нейминг», либо вызывается явно как `/domain-brand-naming`.

Скрипт можно запускать и отдельно от агента:

```bash
plugins/naming/skills/domain-brand-naming/scripts/check-name.sh zorveksa com io ru
```

Он проверяет домены через RDAP или WHOIS, историю в web.archive.org, занятость
имени в npm, PyPI, GitHub, App Store и VK — и явно перечисляет то, что машинно
не проверяется вообще.

## Принципы

Скиллы здесь написаны под одно требование: **результат должен выдерживать
проверку пользователем**. Отсюда правила, общие для всех:

- разделять то, что агент проверяет сам, и то, что закрыто капчей, логином или
  JS-рендером — по второму выдаётся чек-лист, а не выдуманный результат;
- ссылаться на стабильные URL, а не на поисковые запросы в SPA;
- честное «не проверено» всегда дешевле правдоподобной выдумки;
- каждый скрипт проверяется на живых данных до того, как попадёт в репозиторий.
